ABOUT PROJECT

프로젝트 소개

스마트 통학 관리 시스템은 학교 셔틀버스의 운행 정보를 실시간으로 확인하고 학생들의 효율적인 통학을 지원하기 위한 웹 기반 서비스입니다. 학생은 노선과 운행 시간을 쉽게 확인하고, 관리자는 셔틀버스 운행 및 탑승 현황을 효율적으로 관리할 수 있습니다.

CORE FEATURES

주요 기능

🚌

셔틀버스 운행 조회

현재 운행 중인 셔틀버스와 다음 출발 시간을 확인할 수 있습니다.

📍

노선 및 정류장 확인

셔틀버스 노선과 정류장 정보를 쉽게 확인할 수 있습니다.

🎫

탑승 예약 관리

원하는 시간대의 셔틀버스를 예약하고 탑승 정보를 관리합니다.

👥

탑승 인원 관리

노선별 탑승 인원을 확인하여 효율적인 차량 운행을 지원합니다.

🔔

운행 알림

운행 변경이나 지연 등의 정보를 사용자에게 안내할 수 있습니다.

📊

운행 데이터 관리

운행 및 탑승 데이터를 수집하여 통학 서비스를 효율적으로 관리합니다.

TECH STACK

사용 기술

HTML과 CSS를 활용하여 사용자 인터페이스를 구현하고, JavaScript를 이용해 셔틀버스 운행 정보와 사용자 상호작용을 처리합니다. 백엔드 API와 연동하여 조회수, 운행 상태, 탑승 인원 등의 데이터를 동적으로 표시할 수 있도록 설계했습니다.
